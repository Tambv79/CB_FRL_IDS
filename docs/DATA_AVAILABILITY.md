
# Data and code availability statement

## Manuscript wording

> The code, processed metadata, experiment manifests, seed-level results, and analysis artifacts
> supporting this study are publicly available in the CB-FRL-IDS GitHub repository at
> https://github.com/USERNAME/CB-FRL-IDS. Raw CICIDS2017 and CICIoT2023 data are not redistributed and remain
> available from their original providers under their respective terms. Additional supporting
> material is available from the corresponding author upon reasonable request.

## Scope of public material

The Git repository contains code, locked manifests, compact result tables, and validation
records. The complete seed-level evidence is attached to release `v1.0.0` as
`CB_FRL_IDS_REPRODUCIBILITY_ARTIFACT_v1.0.0.zip` with a SHA-256 checksum.
