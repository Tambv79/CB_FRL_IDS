
# Contributing

Contributions that improve reproducibility, documentation, tests, or portability are welcome.

1. Open an issue describing the proposed change.
2. Do not upload raw CICIDS2017 or CICIoT2023 data.
3. Preserve protocol IDs, locked manifests, and scientific claim boundaries.
4. Add or update tests for code changes.
5. Do not overwrite validated evidence; place new experiments under a new protocol identifier.
6. Submit a focused pull request with a clear scientific rationale.

By contributing, you agree that your code contribution is licensed under the repository's MIT
License and your documentation contribution under CC BY 4.0.
