
# Security policy

Please do not disclose suspected vulnerabilities through a public issue before the maintainers
have had a reasonable opportunity to investigate. Report security-sensitive concerns to the
corresponding author at `hungvle@tlu.edu.vn` with the subject `CB-FRL-IDS security report`.

The research code is provided for reproducibility and is not production security software.
Evaluated robustness is limited to the threat models documented in the manuscript and artifact.
